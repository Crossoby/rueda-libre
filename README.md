## Descripción

**Rueda Libre** es un sitio web de alquiler de bicicletas y recorridos guiados en Medellín. Cuenta con tres páginas: **Inicio**, donde se presentan la flota, los servicios y las rutas; **Tarifas**, donde se pueden comparar los precios de alquiler y de los recorridos; y **Reservas**, que incluye un formulario con validación en el navegador y un modal para consultar las políticas de alquiler.

La versión **2.0** está desarrollada con HTML, CSS, JavaScript y Bootstrap 5. El sitio se adapta a móviles, tabletas y computadores, e incorpora Bootstrap Icons y una identidad visual propia basada en los colores Verde Ruta y Naranja Pedal.
