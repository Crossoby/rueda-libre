MINIRETO 3. DISTRIBUCIÓN CON GRID Y FLEXBOX

Usé Flexbox para ordenar elementos principalmente en una dirección. Elegí Grid cuando necesitaba definir columnas y organizar el contenido en filas y columnas.

Estas fueron mis seis decisiones:

Portada: Grid para colocar el texto a la izquierda y la imagen a la derecha. Definí las columnas con fr y centré el texto verticalmente con align-items: center.

Galería de rutas: Grid para repartir las tres tarjetas en columnas iguales y separarlas con gap.

Reservas: Grid para distribuir el formulario y la información de contacto en proporción 2:1. El formulario ocupa dos partes y el contacto una.

Fila del formulario: Grid para colocar dos campos relacionados en columnas iguales. Cada campo conserva su etiqueta.

Encabezado: Flexbox porque la marca y el menú se distribuyen principalmente en una fila.

Pie de página: Flexbox porque sus tres bloques se organizan en una fila y se alinean por arriba.

Las columnas se definen con fr, sin darles anchos fijos en píxeles. La validación del formulario sigue dependiendo de los atributos del HTML, como required, minlength y pattern.

MINIRETO 4. ADAPTACIÓN A MÓVIL

En el bloque responsive dejé una columna como base para móvil. Añadí media queries con min-width: 768px para tablet y min-width: 1200px para escritorio.

En móvil, la marca queda arriba, el menú debajo y centrado, y el pie se organiza en columna. Desde tablet, el encabezado y el pie vuelven a distribuirse horizontalmente. En escritorio, las rutas quedan en tres columnas y las reservas recuperan la proporción 2:1.

Problemas del CSS que ajusté:

La portada, las rutas y las reservas tenían varias columnas incluso con poco espacio. Les di una columna como base y recuperé las otras columnas mediante media queries.

La imagen de portada tenía altura fija y márgenes laterales. Usé altura automática y eliminé los márgenes laterales que podían hacer que las imágenes sobresalieran.

Las tarjetas tenían un mínimo de 20rem, que podía superar el ancho disponible. Ajusté minmax() con min() para permitir que se reduzcan cuando el contenedor es más pequeño.

Las tablas tenían demasiado relleno para un celular. Reduje el relleno y la letra en móvil, ajusté su ancho y permití que el texto se divida dentro de las celdas.
